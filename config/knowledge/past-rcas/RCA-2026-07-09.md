# Card deposits failed with a null pointer after a release
- Id: RCA-2026-07-09
- Date: 2026-07-09
- Component: deposit-p1
- Exception: NullPointerException
- Root cause: A release added a receipt preference lookup that assumed every customer has a preference record. Customers without one hit a null pointer.
- Resolution: The lookup was made to handle a missing record, and a test for customers without preferences was added.

## What happened
A steady trickle of deposit failures started with the release and continued until the fix, at the same line each time.
