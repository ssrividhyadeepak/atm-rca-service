# Withdrawals failed after a configuration push shrank the connection pool
- Id: RCA-2026-05-02
- Date: 2026-05-02
- Component: withdrawal-p1
- Exception: ConnectionPoolExhaustedException
- Root cause: A configuration change lowered the maximum number of connections to the authorization gateway from 50 to 5. The change was not load tested.
- Resolution: The configuration version was rolled back, and a review checklist for configuration changes was introduced.

## What happened
Minutes after a configuration deployment, withdrawals began failing with "connection pool exhausted".
